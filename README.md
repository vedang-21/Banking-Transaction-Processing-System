# Banking Transaction Processing System

## Overview

The Banking Transaction Processing System is a menu-driven application developed in C. It simulates basic banking operations such as account creation, deposits, withdrawals, fund transfers, and transaction history management.

The project demonstrates the practical implementation of fundamental Data Structures and Algorithms concepts.

## Objectives

- Manage customer bank accounts.
- Process deposits and withdrawals.
- Transfer funds between accounts.
- Maintain transaction records.
- Implement basic data structures to organize and process banking information.

## Features

- Account creation and management
- Search and display bank accounts
- Sort accounts by account number and balance
- Deposit and withdraw money
- Transfer funds between accounts
- Maintain transaction history
- Undo previous transactions

## Data Structures Used

| Data Structure | Application |
|---|---|
| Singly Linked List | Account management |
| Queue | Transaction processing |
| Stack | Transaction history and undo operations |
| Linear Search | Searching for accounts |
| Bubble Sort | Sorting account records |

## Project Modules

### 1. Account Management
- Create new accounts
- Display all accounts
- Search for accounts
- Update and delete accounts
- Sort accounts by account number and balance

### 2. Transaction Processing
- Process deposits
- Process withdrawals
- Transfer funds between accounts
- Validate account details and transaction amounts
- Manage pending transactions using a queue

### 3. Transaction History
- Maintain records of transactions
- Display transaction history
- Implement undo functionality using a stack

## How to Run

Compile the integrated C source files using GCC and execute the generated program.

```bash
gcc *.c -o banking
```

Run on Windows:

```bash
banking.exe
```

*The compilation command may need adjustment depending on the final source file structure.*
